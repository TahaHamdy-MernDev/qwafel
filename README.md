# Qwafel Web Platform

A modern, localized Next.js & TypeScript web platform built with Radix UI primitives, Tailwind CSS, React Hook Form, and `next-intl` internationalization.

## Live Demo

- **Production:** [qwafel-ecl6.vercel.app](https://qwafel-ecl6.vercel.app)

## Tech Stack

- **Framework:** Next.js (App Router), React, TypeScript (`strict: true`)
- **UI & Styling:** Tailwind CSS, Radix UI / Shadcn UI
- **Forms & Validation:** React Hook Form, Zod / Hookform Resolvers
- **Internationalization:** `next-intl` (`i18n/`, `messages/`)

## Local Development

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```
